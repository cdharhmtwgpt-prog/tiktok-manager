Kết nối Google Sheet

Dán URL Apps Script Web App đã deploy để đồng bộ dữ liệu.

Hướng dẫn lấy URL
  1. Mở Google Sheet
  2. Đổi tên sheet tab đầu tiên thành Posts
  3. Extensions → Apps Script → dán code từ apps-script.js
  4. Chạy hàm getSheet 1 lần → cấp quyền
  5. Deploy → New deployment → Web app → Anyone → Deploy
  6. Copy URL → dán vào ô trên
